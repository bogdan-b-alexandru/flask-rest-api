# Flask REST API

A lightweight REST API built with Flask as part of a self-directed 
full-stack AI development curriculum.

## Endpoints
- `GET /` — Health check, confirms API is running
- `GET /jobs` — Returns a list of job postings in JSON format

## What I learned
- Setting up a Flask server from scratch
- Creating routes with decorators
- Returning JSON responses with jsonify
- Virtual environments and dependency management with pip

## Stack
- Python 3.12
- Flask

## Part of a larger curriculum
This is Project 2 of 5 leading to a full-stack AI agent app 
built with Python, Flask, PostgreSQL, React, and the Claude API.
